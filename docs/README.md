# 第2回の資料を種類から探す

集まった知見を、探しやすいように種類ごとにまとめます。資料は作者と原典をたどれる形で紹介します。

**[知見・資料を投稿する](https://github.com/AICatchup/catchup-002/issues/new?template=share.yml)** · [参加者ガイド・ファイルの送り方](../PARTICIPATE.md) · [AI向けの入口](../AGENTS.md)

| 種類 | 例えば |
| --- | --- |
| [リンク・参考資料](links.md) | 公式ドキュメント、記事、動画、公開資料 |
| [発表・LT](presentations.md) | 発表スライド、発表で話したこと |
| [活用事例](use-cases.md) | 仕事や制作での使い方、小さな工夫 |
| [作品・デモ](demos.md) | 作ったもの、コード、動くデモ |
| [試した記録](experiments.md) | 試した手順、結果、つまずき |
| [質問・まだ分からないこと](questions.md) | 気になっていること、調べたいこと |
| [その他・新しいカテゴリ](other.md) | どの種類にも当てはまらないものや、分類の提案 |

## 投稿して、一覧に載るまで

[資料・活用事例を投稿する](https://github.com/AICatchup/catchup-002/issues/new?template=share.yml)から、リンクと一言、または短い本文を送れます。GitHubアカウントが必要で、Issueは送信時から公開されます。投稿は任意で、発表していない人や開催後の投稿も歓迎です。

運営が内容と公開範囲を確認し、必要に応じて投稿者に相談して、[資料の記録](../contributions/)を追加し、関連する種類の一覧からリンクします。投稿しただけで一覧に自動追加されるわけではありません。複数の種類に当てはまるときは、同じ記録をそれぞれから参照できます。

## カテゴリを増やす

新しい資料を記録したら、該当する種類のページにも、記録へのリンクと短い説明を追加します。複数の種類に載せるときも、本文は一つの記録にまとめます。

新しい種類が必要になったら、「その他・新しいカテゴリ」で提案するか、PRで追加してください。新しいページを `docs/` に作り、この一覧と投稿フォームの選択肢にも加えます。作者と原典へのリンクは保ってください。[投稿方法](https://github.com/AICatchup/community/blob/main/CONTRIBUTING.md) / [共通方針](https://github.com/AICatchup/community/blob/main/POLICY.md)
