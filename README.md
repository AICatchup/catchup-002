## この回について

開催日：2026年11月7日（土）14:00〜18:00 JST。開催案内は [Codex Catchup #2](https://luma.com/h7gn1d01) を参照してください。

**一人ひとりの当たり前を、みんなの当たり前に。** 最近のリリースと普段の使い方を持ち寄り、LTや実演、交流を通じてキャッチアップします。

共有ハッシュタグ：**#AICatchup**

## 例えば、こんな話

- MCPやAgents APIで試したこと、できること。
- dotsやSpaceの活用例、dotsで開発するときの進め方。
- Codexの設定を見直して便利になった、小さなノウハウ。
- 普段の仕事や開発でのユースケース、作ったもののデモ。
- うまくいかなかったこと、みんなに聞きたいこと。
- 新しく発表された機能で、これから試したいこと。

すでに使えるものと、発表済みで今後の公開を待っているものを分けて共有します。

## 当日の関わり方

話したい人が話せるように、LTの希望を伺いながら進めます。完成した作品に限らず、設定の小技や質問も歓迎します。聞く、試す、交流する過ごし方は自由です。席を替えるきっかけも設けますが、その場に残っても構いません。

主催者も卓を回り、参加者の興味や活動を知って、人と人をつなぎます。初めて会う人が卓に加わったときも歓迎し、気軽に自己紹介してください。
